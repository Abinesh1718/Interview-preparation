🔹 2. How do you make a responsive layout that changes from 3 columns to 1 column on mobile?
we can achice using grid method

.parent{
    display:grid,
    grid-template-column:repeat(3,1fr)
    
}
@media (max-width:768px){
    .parent{
        grid-template-column:1fr
    }
}
