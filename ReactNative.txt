1. What is React Native, and how is it different from React.js?
React Native is a framework that allows developers to build mobile applications using React and JavaScript. Unlike React.js,
which is used for web applications, React Native compiles to native components, enabling cross-platform mobile development for iOS and Android.

2. What are the common performance issues in React Native and how do you fix them?

Unoptimized FlatList → Use keyExtractor, initialNumToRender, windowSize.
Re-renders → Use React.memo, useCallback, useMemo.
Large images → Compress and use CDN.
Avoid anonymous functions in render → Move them outside the render scope.


3. How do you handle device-specific UI in React Native?

Platform.OS (ios or android) for conditional logic.
Platform.select() for styles.
Dimensions API or react-native-responsive-screen for responsive layout.
Safe area handling using react-native-safe-area-context

4. What is the difference between ScrollView and FlatList?

ScrollView: Renders all items at once → bad for large lists.
FlatList: Renders only visible items → performense for long lists

10. How would you implement dark mode in a React Native app?

Use Appearance API or useColorScheme() hook.
Theme-based implementation using context or libraries like react-native-paper or styled-components.

11. How do you handle offline data in React Native apps?
Use AsyncStorage for local storage.
Use NetInfo to detect network status.
Libraries like redux-persist, realm, or WatermelonDB help manage offline state and sync.

12. How do you handle image caching in React Native?
Use third-party libraries like react-native-fast-image for optimized image loading and caching.
Avoid reloading images unnecessarily by caching URIs

14. What steps do you follow to release a React Native app?
iOS: Archive via Xcode and upload to App Store.
Android: Generate release.apk or aab and upload to Play Console.
Use react-native-config for managing env variables.

15. How do you handle app crashes or logs in production?
Use Sentry or BugSnag for real-time crash reporting.
Use Flipper for debugging during development.
Firebase Crashlytics for mobile crash analytics.
